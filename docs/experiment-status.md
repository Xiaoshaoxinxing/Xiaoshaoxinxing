## 版本与结果

| 实验 | LLM 可见输入 | MER2023 Hit Rate | MER2024 Hit Rate |
| --- | --- | ---: | ---: |
| 原基线 | 单融合 token | 42.9628% | 43.0342% |
| 字幕对照 | 融合 token + 原始字幕 | 61.0147% | 56.6184% |
| 当前 | 融合 token + 原始字幕 + 各一个独立音频/视频 token | 61.5393% | 暂缓，未完成 |

当前 MER2023 相对字幕对照提高 0.5246 个百分点。单次结果不构成多随机种子下的稳定收益证明。官方对照的主干、编码器和训练预算不同。

三个本项目实验均使用 31,327 条 MER-Caption+ 样本，各一次，10,443 个优化器步；仅主路径 CE，microbatch=1、累积=3、seed=42。分别重新初始化，不顺序微调；最终 step 10443 为预定评测检查点。训练样本顺序和学习率一致。

## 源码与复现边界

完整模型实现、三组训练/评测配置、独立 token 和字幕兼容测试、训练恢复/周期保存测试随库发布。新增独立投影读取同一前端的末位置向量，不是绕过前端的原生音视频旁路。

公开入口是 [运行协议](protocol.md) 的 `tools/mer_omni.py` 命令。`tools/run_av_tokens_ablation.py` 保留服务器调度实现，依赖本地预注册报告，不能在缺少报告的克隆中直接运行，也不代表当前仍获准评测 MER2024。

模型权重、数据、校准产物、原始训练日志、逐样本预测及本地诊断缓存不随 Git 发布。结果快照 [experiments-20261016.json](results/experiments-20261016.json) 记录指标、检查点和源文件指纹，支持标识本次实验，但不能代替持有原始产物后的独立复算。

离线测试使用当前依赖环境、合成媒体和微型真实 Omni 组件，不要求实际 3B 权重。独立 token 加入前的模型源码作为 `tests/fixtures/model_before_av.py` 固定夹具发布，供旧版本初始化、loss 和生成输出精确对照。
